# Receivables close after bank chargebacks

Finance needs a reusable XLSX workbook for the attached lockbox ledger. Complete the two output sheets in template.xlsx and submit your file using the local command `./submit filename.xlsx`. Finance accepts the first file only. Work within this trial directory, with local spreadsheet software or Python. Python with openpyxl and a headless LibreOffice calculation engine are available. You may create helper sheets, use code and test before submitting. Keep all input cells and the output ID lists unchanged in the submitted workbook. No external links, macros, network access or access to other trial files. Budget 900 seconds.

All amounts are integer cents. Replay Bank events in ascending **Sequence**. Include an event only when both its value day and its recorded day are at or before their respective inclusive Cutoff values. Filter each event independently. An invoice opens on its Open day and is eligible from that day even if its due day is later. It starts at face value. A receipt pays down the currently outstanding balances of eligible invoices from its own legal entity, in ascending (Due day, Open day, Invoice ID) order. Any excess stays unapplied on that particular receipt. Do not automatically reapply excess when another invoice opens.

A reversal names ONE original receipt. First use its remaining unapplied cash, then unwind that receipt's surviving applications in reverse original application order. Each such reversal reopens the affected invoice by the amount unwound. Leave allocations made by other receipts intact. Multiple reversals against the same receipt consume only what remains on that receipt. For a reversal that exceeds its surviving receipt, report the excess as unfunded on that reversal. If the original receipt was excluded, the whole included reversal is unfunded.

On Close, provide gross cash applied (all original applications before reversals), total applications reversed, and the closing outstanding balance for each listed invoice. An invoice that opens later than the value cutoff has zero for all three columns. On Receipt control, show remaining unapplied cash for each receipt and unfunded amount for each reversal. Use zero for the other column and for excluded events. Output cells must be live Excel-compatible formulas.

The verifier recalculates the submitted workbook in LibreOffice under the original inputs and separately after changing cutoff dates, receipt and reversal amounts, invoice dates, and source row order. Inputs retain the same number of invoices and events. IDs and sequence numbers remain unique. The formula for an output ID must continue to follow its source record if a register is reordered. All 48 amounts across both sheets are checked in each state. Finance awards partial credit for each correct formula-backed amount and accepts the whole workbook only if it passes every state.
